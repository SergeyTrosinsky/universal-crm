# Демонстрация: «Один день в компании «Континент»»

Рабочий пример для показа CRM: одна компания, три направления — **автосервис**, **салон красоты** и
**корпоративные продажи** — работают в одной системе. Данные нарисованы вымышленные.

## 1. Подготовка (один раз перед съёмкой)

1. Запустите Docker Desktop и приложение (`run.bat` или `admin.bat` → пункт 8).
2. `admin.bat` → пункт **13** «Загрузить демо-сценарий». Он сам сделает копию текущей базы
   (`backups\crm_before_demo_….dump`), удалит старых пользователей и данные и загрузит пример.
   На вопрос про VIN и госномер отвечайте **N** — их мы создадим в кадре.
3. Откройте `http://localhost:8000`, масштаб браузера 100%, уберите лишние вкладки и закладки,
   окно браузера — 1920×1080 (или 1280×720 для записи в HD).
4. Для записи удобны **OBS Studio** или встроенная запись Windows (**Win+G**), скриншоты — **Win+Shift+S**.

Вернуть свои данные после съёмки: `admin.bat` → пункт **7** → выберите файл `crm_before_demo_…`.
Вернуть только своего администратора, не трогая демо: `docker compose --env-file .env.docker exec app python -m app.cli create-admin --email you@company.ru --name "Ваше имя"`.

## 3. Скриншоты (4 основных + 2 запасных)

Делайте под **director@kontinent.demo**, после съёмки видео (чтобы поля VIN и Госномер уже были).

| № | Что показать | Где | На что обратить внимание |
|---|---|---|---|
| 1 | Главная со статистикой | `/` , период «Год» или «Всё время» | карточки, распределение по статусам, график по месяцам, рейтинг по ответственным |

## 4. Сценарий видео (≈2 минуты)

Говорите спокойно, мышью показывайте то, о чём говорите. Текст — примерный, своими словами.

**0:00–0:15 · Главная (director).**
Покажите главную. *«Это сервисная компания «Континент»: автосервис, салон красоты и корпоративные продажи.
Все три направления ведутся в одной CRM. Вот статистика: сделки по статусам, выручка, динамика по месяцам и
рейтинг сотрудников.»*

**0:15–0:55 · Настройка без кода (director).**
**Настройки → Поля** (вкладка «Заказы») **→ Новое поле**; можно и из «Шаблоны» → «+ Добавить поле» у «Автосервиса».
Название **VIN**, тип «Текст», шаблон **«Автосервис»** → создать.
Повторите: **Госномер**, «Текст», шаблон «Автосервис». *«Автосервису нужны VIN и госномер. Я добавляю их
сам, без программиста, и ничего не перезапускаю. Поля относятся только к шаблону «Автосервис» — в салоне
красоты они не нужны, там свои: мастер, услуга, дата визита.»*
(Мельком покажите **Шаблоны**: два шаблона, поля у каждого.)

**0:55–1:25 · Работа сотрудника (выйти → Денис).**
**Выйти** → вход `denis@kontinent.demo`. *«Теперь работает приёмщик. Он видит только свои заказы.»*
**Заказы** → «Диагностика ходовой Toyota Camry» → **Изменить**: VIN `XTA210930N1234567`,
Госномер `А123ВС 777` → сохранить. Прокрутите вниз к **истории**: *«Каждое изменение записывается: кто,
что и когда. Добавим заметку для коллег.»* Напишите заметку: «Запчасти заказаны, срок — завтра».
Смените статус на «Ожидает оплаты».

**1:25–1:50 · Список по блокам и поиск (Марина).**
Вход `marina@kontinent.demo`. **Заказы**: *«Менеджер видит всех. Заказы разложены по направлениям, поиск
общий — вводим «Camry» и сразу находим.»* Покажите фильтр по статусу и **Доску**: перетащите карточку
«Компьютерная диагностика Ford Transit» в «В работе».

**1:50–2:05 · Роли (Анна).**
Вход `anna@kontinent.demo`. *«А это мастер салона — отдельная роль, которую администратор собрал из
прав сам: только свои записи, настроек нет.»* Покажите её короткий список заказов.

**2:05–2:15 · Финал.** *«CRM не привязана к одной отрасли: поля, статусы, шаблоны и названия настраиваются в
интерфейсе. Есть импорт и экспорт Excel, история изменений, Docker и резервные копии.»*

### Расширенная версия (для живой демонстрации, +2–3 минуты)
- **Задачи** (Марина): создать задачу Ольге «Подтвердить запись…», показать просроченные задачи и фильтр по исполнителю («Все сотрудники»).
- **Общие настройки**: поменять термины («Заказы» → «Записи») и вернуть обратно.
- **Статусы**: добавить статус «Ожидает запчастей» (цвет, тип «в работе»), показать его на доске.
- **Клиенты**: поиск, карточка клиента с его заказами и историей.
- **Импорт/экспорт**: Клиенты → «Импорт / экспорт» → Excel (.xlsx), затем «Загрузить из файла…» с предпросмотром.
- **Роли** (director): открыть «Мастер салона», показать отдельные права; создать роль «Бухгалтер».
